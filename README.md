# Sales Performance Dashboard

An interactive sales performance dashboard built in Power BI from the supplied sales dataset.

## Analysis

- Imported the sales data and prepared a cleaned dataset, including handling null values and removing duplicate records.
- Analyzed sales trends by month, quarter, and year.
- Identified top-selling products and low-performing items.
- Compared sales across regions and product categories.
- Created key performance indicators for total revenue, total profit, and sales growth rate.
- Built the interactive dashboard in Power BI.

## Project files

| File | Description |
| --- | --- |
| `Sales Performance Dashboard.pbix` | Power BI report and interactive dashboard. |
| `Dataset_Cleaned.csv` | Cleaned sales dataset used for analysis. |
| `Sales_Performance_Dashboard_Dataset.csv` | Supplied source dataset. |

The CSV files contain 5,901 data rows each. The cleaned dataset has 21 columns; the supplied source file also includes extra index columns.

## Open the dashboard

Download or clone this repository and open `Sales Performance Dashboard.pbix` in Power BI Desktop. The CSV files are included as the report's data sources; if Power BI prompts for a file path, point it to `Dataset_Cleaned.csv` in the project folder.
